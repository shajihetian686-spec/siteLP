# 設計判断記録

## 2026-04-20: プロジェクト初期構築 - カラースキーム・レイアウト方針

### 判断者
- エージェント: Builder

### 背景
- Web制作サービスのLPデザイン完成イメージ（画像）を忠実にHTML/CSSで再現する
- デザイン提案ではなく再現が目的

### 選択肢
1. 案A: フレームワーク（Bootstrap/Tailwind）を使用
2. 案B: バニラCSS（フレームワークなし）で実装

### 決定
- 採用案: 案B（バニラCSS）
- 理由: デザインの細かな再現にはフレームワークの制約が邪魔になる。余白・角丸・シャドウなど、画像に合わせた微調整が必要なため、CSS変数を使ったバニラCSSが最適。

## 2026-04-20: アニメーション方針

### 判断者
- エージェント: Builder

### 背景
- JavaScriptは最小限という要件

### 選択肢
1. 案A: AOS.jsをCDNで導入
2. 案B: Intersection Observerで自前実装
3. 案C: アニメーションなし

## 2026-09-14: エディトリアル・コーポレートへの全面再設計

### 判断者
- エージェント: Builder
- 指示: ユーザー明示（参考サイト https://www.sanzen-design.jp/ のデザイン・アニメーションへ寄せる）

### 背景
- デザイン凍結下だったが、ユーザーからデザイン・アニメーションの変更が明示された
- カードUI・角丸を避け、余白と文字サイズのコントラストで構成する
- 内容は維持しつつ、大型サイト管理運営・サーバー構築・セキュリティチェックを売りにする

### 決定
- トーン: ミニマルでエディトリアルなコーポレート。大きな明朝見出し、細い罫線、小さな英字ラベル、大胆な写真配置
- フォント: 見出し Noto Serif JP / 本文 Noto Sans JP / 数字 Syne / ラベル DM Mono
- 配色: 紙色のクリーム地（#F3EFE6 / #F7F3EA）と墨色。アクセントは落ち着いたブラウン（#6B4A32）
- セクション順は維持。お悩み・理由・サービス・比較・対象に、市立小中学校／地区消防本部、サーバー構築、既存サイトのセキュリティチェックを追加
- アニメーション: Intersection Observer によるマスクreveal（clip-path）、fade-up、ゆるいparallax。出現をずらし、1.1〜1.35秒の緩やかなイージング。外部ライブラリは使わない
- 角丸・カード面は使わない。リストと罫線で区切る

## 2026-09-17: 実績スライドを transform ではなく DOM リサイクルに

### 判断者
- エージェント: Builder
- 指示: ユーザー明示（最初は表示されるが、動くうちに消えていく）

### 背景
- 件数を減らしても iPhone Chrome では最初だけ見えて、流れ始めると消える
- `translate3d(-50%)` で超横長トラックを GPU レイヤーに載せると、動き出したあとテクスチャが落ちる。複製側の画像も画面外扱いでデコードされない

- 先頭カードが枠外に出たら末尾へ回し、移動は `margin-left`（transform なし）
